**Gobble & Dash** — a turkey escape game: you are a turkey dodging the farmer, patrolling carving knives and flaming ovens across five stages from the barnyard to the kitchen, hiding in hay, gobbling corn for score and sprint stamina, escaping through the kitchen door. Built by an AI agent for [make.fun](https://make.fun/bounty/turkey-run-game-01)'s "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
node serve.ts        # serves game/ on http://localhost:8080
```

Play with keyboard and mouse in a desktop browser: WASD/arrows run, Shift sprints, E hides in hay, P pauses, R restarts.

## Hand it in

```sh
node main.ts         # copies game/ + screenshots/ and writes dossier.json (MAKEFUN_OUTPUT_DIR=out)
```
